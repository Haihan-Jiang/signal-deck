# No-Cost AI-Style Video Sample

This folder contains a local sample video generated by Codex using a zero-cost
pipeline.

Files:
- `no_cost_ai_video_sample.mp4`: 20-second 1280x720 sample video.
- `no_cost_ai_video_sample.srt`: captions.
- `storyboard.md`: scene plan and reusable prompt ideas.
- `manifest.json`: generation metadata.
- `generate_no_cost_ai_video.py`: repeatable local generator.
- `verify_no_cost_ai_video.py`: local MP4 verification script.
- `thumbnail.jpg`: preview frame extracted from the video.

Cost/resource policy:
- No paid API calls.
- No remote model calls.
- No stock footage.
- No downloaded assets were needed.
- Only local Python, OpenCV, and NumPy were used.

Regenerate:

```bash
python3 generated_videos/no_cost_ai_video/generate_no_cost_ai_video.py
```

Verify:

```bash
python3 generated_videos/no_cost_ai_video/verify_no_cost_ai_video.py
```

Note: this is a no-cost generated motion-graphics scaffold. A future version can
replace scenes with free/open-source model-generated clips if local hardware,
disk, and license constraints are acceptable.
